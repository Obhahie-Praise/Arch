# Arch — Information Architecture

## Primary Navigation

Desktop uses a top navigation bar.

```text
ARCH

Home
Opportunities
Saved
Applications

Profile
```

The logo sits on the left, primary links are centered, and the user's profile button sits on the right.

Mobile may use a different navigation pattern.

## Home

Home contains:

- overview metrics
- recent matches
- recent pursuits
- profile improvements

Home should remain concise.

## Opportunities

```text
Opportunities
├── All
├── Jobs
├── Grants
└── Hackathons
```

Users can search and filter opportunities.

## Opportunity Detail

The detail page contains the complete opportunity information and personalized analysis.

It is separate from the main Home or Opportunities content.

## Saved

Saved contains opportunities the user has intentionally kept for later.

Initial categories:

- All
- Jobs
- Grants
- Hackathons

Additional pursuit states may be introduced without turning Saved into a complex project-management system.

## Applications

Applications contains opportunities the user is actively pursuing or has submitted.

It should make it easy to understand:

- what is in progress
- what has been submitted
- what needs attention

## Profile

Profile contains the user's information used for matching.

It is more than an account settings page.

## Settings

Settings contains account and application preferences such as:

- account
- notifications
- privacy
- connected accounts
- usage
