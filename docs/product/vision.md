# Arch — Product Vision

## Vision

Arch exists to help people find opportunities worth pursuing and actually pursue them.

The internet contains thousands of opportunities across jobs, grants, hackathons, fellowships, competitions, and other programs.

The problem is not simply finding them.

The problem is knowing:

- which ones are relevant
- whether the user is eligible
- why the opportunity fits
- what is required
- what the application process looks like
- what to do next

Arch turns scattered opportunities into a structured, understandable, personalized experience.

## Core Loop

**DISCOVER → UNDERSTAND → PURSUE**

### Discover

Find relevant opportunities from across the web.

### Understand

Explain the opportunity, its requirements, deadline, organization, application process, and relevance to the user.

### Pursue

Help the user prepare, track, and continue pursuing the opportunity.

The actual application submission normally remains on the original opportunity provider's website.

## Product Philosophy

Arch should feel like a serious product rather than an AI demonstration.

Intelligence should be present in the experience without becoming the interface itself.

The user should not need to understand how the system works to benefit from it.

## Long-Term Direction

Arch can eventually support many opportunity categories and increasingly useful application assistance.

The product should expand from discovering opportunities into becoming a user's persistent system for pursuing them.

Expansion must not compromise the simplicity of the core experience.
