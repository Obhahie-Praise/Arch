# Arch — V1 Scope

## V1 Includes

### Product

- Account creation and authentication
- Social authentication support
- User profile
- Opportunity discovery
- Jobs
- Grants
- Hackathons
- Opportunity search
- Opportunity filtering
- Personalized matching
- Opportunity detail pages
- Saved opportunities
- Pursuit tracking
- Application status tracking
- External application links

### Platform

- Next.js web application
- Cloudflare Worker backend
- Backend-owned authentication
- Cloudflare database
- Background processing
- Scheduled opportunity discovery
- AI-assisted opportunity analysis

## V1 Does Not Include

- Autonomous application submission
- Browser extension
- Mobile application
- Generic AI chat interface
- Large analytics dashboard
- Complex application Kanban
- Every possible opportunity category
- Microservice architecture
- Unnecessary infrastructure

## Scope Principle

If a feature does not meaningfully improve:

**DISCOVER → UNDERSTAND → PURSUE**

it should be questioned before being added to V1.
