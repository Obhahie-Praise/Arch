# Arch — Core Journey

## Account Creation

After creating an account, the user is taken directly to Home.

Arch does not use a traditional multi-step onboarding flow.

## Initial Home State

If the user has not created a profile, Home contains a clear prompt explaining that their profile is required before Arch can provide meaningful personalized opportunities.

Example:

> **You're almost there.**
>
> Create your profile so we know enough about you to find opportunities that actually match you.

The user is directed to Profile.

## Profile

The Profile page contains the information Arch needs to understand the user and improve matching.

The form may be relatively long.

It should remain:

- straightforward
- familiar
- clearly structured
- honest about why information is being requested

The goal is not to artificially reduce the number of fields.

## Home After Profile Completion

Home becomes a concise personal opportunity overview.

It should contain:

- useful account/opportunity metrics
- recent matches
- recent pursuits
- profile information that could meaningfully improve matching

Home should not become a long dashboard.

## Opportunity Discovery

Users can browse and search opportunities.

Opportunity cards provide enough information to decide whether an opportunity is worth opening.

The complete opportunity is shown on its own detail page.

## Opportunity Understanding

The opportunity detail page provides:

- opportunity information
- deadline
- requirements
- organization information
- application process
- source
- personalized match information
- potential concerns
- preparation requirements

## Pursuit

A user can save or pursue an opportunity.

Pursuing means the user has decided to actively go after it.

Arch can help prepare and track the pursuit.

## Application

The actual application normally occurs on the original opportunity provider's website.

Arch provides the appropriate external application link.

The user can return to Arch and update the opportunity's application state.

## Persistent Loop

```text
DISCOVER
   ↓
UNDERSTAND
   ↓
PURSUE
   ↓
APPLY
   ↓
TRACK
   ↓
BETTER PROFILE
   ↓
BETTER MATCHES
```
